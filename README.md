# java-medication-schedule

Java 17 dose interval checker using UTC instants. Calculates the next scheduled dose and reports overdue time; it does not decide whether a missed dose should be taken.

Compile: `javac MedicationSchedule.java`. Run: `java MedicationSchedule 2026-10-03T08:00:00Z 8 2026-10-03T17:00:00Z`.
